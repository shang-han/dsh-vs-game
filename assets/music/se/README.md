# SE（技能音效）目录

放置游戏内技能/交互音效，推荐使用 CC0 / Public Domain 素材，避免额外署名负担。

命名建议：
- skill-strike.mp3      划除
- skill-evolve.mp3      超武进化
- levelup.mp3           升级
- hit.mp3               命中
- crit.mp3              暴击
- chest-open.mp3        开箱
- craft-success.mp3     合成成功
- craft-fail.mp3        合成失败
- record-eject.mp3      唱片弹出
- ui-click.mp3          UI 点击

格式建议：
- 优先 ogg/mp3
- 单文件尽量小于 200KB
- 统一响度，避免音量差异过大
