# GPT 龙娘 · 1.0.2

作者：**Asryto**  
源码仓库：https://github.com/scarlet20252025-cloud/Coopanion-Skin-Design  
源码目录：`packs/gpt-dragon-v005-r25`  
目标平台：Coopanion，形象包 API 2。

## 安装

在 Coopanion 的「装扮 → 导入」中选择 ZIP，然后选用「GPT 龙娘」。ZIP 根目录应直接包含 `figure.json`，无需另外安装依赖。版本升级保留同一形象 ID `gpt-dragon-v005-r25`，避免产生重复条目。

## 形象与互动

银白头发、浅紫龙角与翅膀，半身近景封面。支持 39 个动作及表情标签，包括招手、走跑、跳舞、坐下和晕乎。眉毛、呆毛、翼与尾部独立驱动；短点击触发呆毛晃动，提起时慌张并快速振翅。招手时耳朵位于手臂后、脸侧头发位于手臂前。

晕乎沿用原坐姿的身体、裙摆和腿部，仅双臂自然垂向两侧，配合圈圈眼与星星。跳舞的飘动音符由 Coopanion 官方 kit 提供。呆毛根部先在连续头部底图中清除旧轮廓，再叠加独立动态呆毛。
